# Web-Development-Foundations Structure

This repository is the canonical web and JavaScript monorepo. It intentionally
backs `Web Development Foundations`, `JavaScript Level 1: JavaScript Superstar`,
and `JavaScript Level 2: JavaScript Master`.

Prefix ownership:

- `WDF-*`: Web Development Foundations
- `JSS-*`: JavaScript Level 1
- `JSM-*`: JavaScript Level 2

Active public folders use the modern wrapper shape with `README.md`, `starter/`,
and `solution/`. New material should keep the prefix boundary clear and should
be linked from the live catalog in the same change.
