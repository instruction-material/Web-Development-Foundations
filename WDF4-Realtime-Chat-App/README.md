# WDF4 Realtime Chat App

Build a small chat or notification app that teaches real-time connections,
server events, and deployment considerations.

## Outcomes

- understand long-lived client/server connections
- run a Node.js server that coordinates browser clients
- compare HTTP request/response to event-based real-time updates
- think about rooms, nicknames, and basic moderation concerns


## Front-end prerequisite

The [local notification state lab](local-client/README.md) teaches views,
fixtures, bounded state, async loading and recovery before the live server.
Its standalone starter/reference roles use a loopback file server with Node.js
24 and require no package installation. The original live-chat roles above
remain the later server exercise.
