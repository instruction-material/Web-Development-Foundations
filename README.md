# Web Development Foundations

Starter and solution material for the Web Development Foundations course.

## Canonical Course Scope

This repo intentionally backs these public courses in the live classes catalog:

- Web Development Foundations
- JavaScript Level 1: JavaScript Superstar
- JavaScript Level 2: JavaScript Master

The old standalone local JavaScript folders were exact duplicates and are not
canonical sources. Keep shared browser, JavaScript, and full-stack starter
material here unless the public catalog is changed to point at separate
published repos.

## Labs

- `WDF1-Portfolio-Custom-Domain`
- `WDF2-Notes-App-with-MongoDB`
- `WDF3-Booking-Contact-App`
- `WDF4-Realtime-Chat-App`
- `WDF5-Separate-Deployment-Lab`

Each lab contains a `starter/` directory for students and a `solution/`
directory for instructor review.
